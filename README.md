# Thief Write — 隐写盲打

一个用于在公共场合盲打私人内容的 VS Code 扩展，输入的真实内容不会显示在编辑器里。

## 使用

先像平常一样打开要编辑的真实文件，然后按 `Ctrl+Alt+T` 进入隐写模式。此时当前标签会切换成隐身视图，正文不再显示。

按 `Ctrl+Alt+N` 可以隐藏标签名称，如 `Untitled-1`。

再次按 `Ctrl+Alt+T` 即可退出隐写，回到正常的明文视图。`Ctrl+Alt+R` 可以开关右下角的状态提示，在隐写模式下，它会显示光标两侧的一小段真实内容，方便确认当前输入位置。

## 安装

开发运行：

```bash
npm install
```

然后在 VS Code 中按 `F5` 启动扩展开发主机。

打包：

```bash
npm run package
```

生成 `.vsix` 后即可手动安装。
