# Thief Write — 隐写盲打

一个用于在公共场合盲打私人内容的 VS Code 扩展。输入的真实内容不会显示在编辑器里，而是保存到自己选择的文件中，屏幕上只显示一份伪装文本。

## 使用

按 `Ctrl+Alt+O` 选择要保存内容的文件，按 `Ctrl+Alt+W` 即可打开上次使用的文件。打开后直接输入即可，真实内容会写入文件，而编辑器中显示的是伪装内容。

`Ctrl+Alt+T` 可以在原文和伪装视图之间切换，`Ctrl+Alt+R` 可以开关右下角的真实字符提示。

默认按真实字符的宽度打码。汉字和中文标点显示为 `口`，字母、数字等半角字符显示为 `·`。可以用命令面板（`Ctrl+Shift+P`）执行 **Thief Write: 选择伪装文本源文件** 挑一个本地文件作为伪装文本；要回到打码模式，执行 **Thief Write: 清除伪装文本源（回到占位符显示）** 即可，无需手动改设置。伪装文本会循环使用。

## 注意事项

这个扩展没有实现 `Ctrl+Z` / `Ctrl+Y`，因为用户无法保证一次撤销会撤销掉多少字，为了防止文本错乱，我们不提供撤销与恢复功能。拓展仅允许以下操作：

- 文字输入
- `←` / `→` 光标移动
- 鼠标选择位置
- `Backspace` 删除左字符（注意 `Delete` 删除右字符暂时不被支持）

## 安装

开发运行：

```bash
npm install
```

然后在 VS Code 中按 `F5` 启动扩展开发主机。

打包：

```bash
npx vsce package
```

生成 `.vsix` 后即可手动安装。
